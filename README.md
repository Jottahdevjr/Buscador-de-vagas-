# Buscador-de-vagas-
Buscador inteligente de vagas de emprego que identifica oportunidades com maior compatibilidade com o currículo do usuário, realizando buscas em plataformas como Gupy e Remote Jobs. O objetivo é facilitar a procura por emprego, automatizando a descoberta de oportunidades e priorizando vagas alinhadas ao perfil profissional do candidato.
